# AI Education Project｜AI 教育開放原始碼專案

## 專案介紹｜Introduction

本專案是一項免費、開放原始碼的 AI 教育工具，目的是協助教師與學生透過互動式網頁學習人工智慧、機器學習及生成式 AI 的基礎概念。

This is a free and open-source educational project designed to help students and educators learn the fundamentals of Artificial Intelligence, Machine Learning, and Generative AI through interactive web-based activities.

## 線上體驗｜Live Demo

https://ai-education-project.netlify.app/

## 主要功能｜Features

- 繁體中文 AI 基礎知識互動測驗
- 五道選擇題及即時答案解析
- 學習進度與答題成績顯示
- 可重新測驗
- 支援桌上型電腦、平板及手機
- 使用 HTML、CSS 和 JavaScript 開發

## 使用方法｜Getting Started

下載或複製本專案，使用瀏覽器開啟 `index.html`，即可在本機使用互動測驗。

Download or clone the repository and open `index.html` in a modern web browser.

GitHub Repository:

https://github.com/20251123/ai-education-project

## 教育應用｜Educational Applications

本專案可供教師用於 AI 入門課程、課堂即時測驗、教學示範，以及學生的前端網頁程式設計練習。

Educators can use this project for introductory AI courses, classroom quizzes, teaching demonstrations, and web development exercises.

## 開放協作｜Contributing

歡迎教育工作者及開發者透過 GitHub Issues 提供建議，或透過 Pull Requests 提交程式碼改善與教學內容更新。

We welcome suggestions, bug reports, and contributions through GitHub Issues and Pull Requests.
